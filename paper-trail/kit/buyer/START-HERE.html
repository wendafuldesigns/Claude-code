Paper Trail

Scan a receipt. Check the details. Find it again when you need it.

Set it up in 3 steps

  1. Unzip this folder and open it in Claude Code. In the desktop app, start a new session and pick the folder. In the terminal, go into the folder and type claude.
  2. Type this and say yes when Claude asks:
    Set up Paper Trail
  3. Open the link Claude gives you. Save it, and send it to your phone.

Then tap Take a photo. The first time, Claude asks to read the photo. Say yes.

You need a Claude account that can publish artifacts, and about 10 minutes. Not sure? Ask Claude Code: Can you publish an artifact? Each scan uses a little of your own Claude usage.

Stuck, or want to know more? Open more/GUIDE.html. It covers your first scan, using it with family and the Household Hub, updates, and what to do if something goes wrong.
